# homebrew-agman

Homebrew tap for [agman](https://github.com/memandip/agman) — agent manager: switchable
config profiles for AI coding agents.

```bash
brew install memandip/agman/agman
```

Or tap first, then install:

```bash
brew tap memandip/agman
brew install agman
```

Upgrade with `brew upgrade agman`. Install the development version with
`brew install --HEAD memandip/agman/agman`.

The formula here is bumped automatically when a new agman release is tagged.
